## Proposal

The system should provide banking services for clients. In particular helping clients transfer money and pay bills. The goal of the project is to create a working application where users can transfer "fake" digital currency between accounts. This project targets the difficulty of sending money in todays society.

The main information system should be able to do at least the following:
- authenticate user
- handle user CRUD
- handle account CRUD
- handle transfers
