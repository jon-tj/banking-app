# Banking App

This is a simple demo application to get comfortable working with the SDLC in engineering software.

## About this project

This project is an introduction into the Software Development Lifecycle (SDLC) where the implementation part is taken care of by AI. The focus of this project is therefore to produce artifacts and documentation that is robust and precise enough that an agent can independently implement the entire project in one prompt.
